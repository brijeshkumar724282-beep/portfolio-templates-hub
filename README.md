# Portfolio Templates Hub

A free public hub to browse, preview, and download three portfolio templates. Clean light theme, one solid accent, motion on scroll.

## Templates featured

1. Minimal Editorial — for writers and photographers. Serif, calm, light and dark toggle.
   Live: https://brijeshkumar724282-beep.github.io/portfolio-minimal-editorial/
   Repo: https://github.com/brijeshkumar724282-beep/portfolio-minimal-editorial
2. Creative Developer — for engineers. Terminal card, bento grid, dark theme.
   Live: https://brijeshkumar724282-beep.github.io/portfolio-creative-developer/
   Repo: https://github.com/brijeshkumar724282-beep/portfolio-creative-developer
3. Visual Designer — for UI UX and brand designers. Marquee, gallery, case overlays.
   Live: https://brijeshkumar724282-beep.github.io/portfolio-visual-designer/
   Repo: https://github.com/brijeshkumar724282-beep/portfolio-visual-designer

## Features

1. Hero with headline, subcopy, stats, and CTA
2. Template cards grid with pure CSS thumbnails, Live Preview and Get Code buttons
3. Compare table showing which template fits whom
4. How to use section with copy buttons for git clone commands
5. Footer with MIT license note

## How to run

```bash
npm install && npm run dev
```

Build for GitHub Pages (uses relative base path):

```bash
npm run build
```

Then serve the `dist` folder anywhere static.

## Assumptions

* Thumbnails are pure CSS shapes so the site works offline with zero image assets.
* One solid accent color is used throughout, no gradients anywhere.
* Node 20 used for local verification.
